# Carnet de voyage Hors ligne

Petit gestionnaire de documents de voyage, installable sur iPhone et Android, qui fonctionne hors ligne.

Les documents ajoutés restent uniquement dans le téléphone (IndexedDB). Ce dépôt ne contient que le code de l'application.

## Installer sur iPhone

1. Ouvrir l'adresse GitHub Pages du dépôt dans Safari.
2. Bouton Partager, puis « Sur l'écran d'accueil ».
3. Ouvrir l'app une première fois avec internet. Elle fonctionne ensuite sans connexion.

## Mettre à jour

Après une modification, changer la version `CACHE` dans `sw.js` pour que le téléphone récupère la nouvelle version.
